# AI 需求提报表

三语（中文、Türkçe、English）静态网页，可直接部署到 GitHub Pages。申请人、业务经理、产品经理、现有流程步骤、改进目标和 AI 功能都在浏览器中填写；流程文件和参考表格可选。

当前版本没有接收服务器。三页可随时切换；顶部“导出 Excel”可在未填完时下载当前草稿，按人员与业务、现有流程、改进与 AI、附件清单分表展示。Excel 不嵌入附件文件；“下载提报包（含附件）”另生成包含附件的 JSON 文件。两种导出都只在浏览器本地处理，不会把业务数据发送到 GitHub。刷新后需要重新选择附件。

Excel 导出使用随网站一同发布的 SheetJS Community Edition 0.18.5；许可证见 `vendor/LICENSE.txt`。

本地预览：在此目录运行 `python3 -m http.server 8765`，打开 `http://127.0.0.1:8765/`。
